NovaBot

A lighthearted Slack bot crafted to make your workplace more engaging and fun. NovaBot delivers random cat facts, generates humor with quick jokes, and features a built-in ping command to check response latency. It's designed to boost team morale, entertain coworkers, and keep daily communication lively in team channels.

AxionOS

An experimental WebOS project focused on creating a basic desktop interface inside the browser. AxionOS aims to feature draggable windows, simple desktop icons, a customizable layout, and lightweight file management. The project is currently under active development and will be updated over time to improve performance and add new capabilities.
